# SatAir Sync

سكربت بسيط لجلب مباريات اليوم والغد بالعربية وتوقيت مصر، ثم حفظها في JSON يمكن قراءته من موقع GitHub Pages أو أي تطبيق آخر. يقرأ أولا وثيقة `matchDays` المنشورة في Firebase الخاصة بالتطبيق، ويستخدم YSScores كمسار احتياطي عند عدم توفر الوثيقة.

## الملفات المهمة

- `sync.py`: الجلب والتحديث والكاش.
- `data/matches.json`: المباريات والحالة والنتيجة والقنوات المرتبطة بها.
- `data/channel_cache.json`: كاش مستقل للقنوات التي ظهرت في المباريات.
- `data/channels.json`: كتالوج القنوات والترددات والأقمار المستخرج من نسخة التطبيق.
- `.github/workflows/sync.yml`: تشغيل تلقائي كل 10 دقائق.

## التشغيل محليا

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python sync.py --days 2
```

كل الأوقات تُحفظ كما تُعرض من مصدر المباريات بالعربية، مع اعتماد `Africa/Cairo` في حساب اليوم والتشغيل. السكربت لا يعيد طلب تردد القناة إذا وجدها في `data/channels.json` أو `data/channel_cache.json`؛ بل يطابق اسم القناة بعد إزالة المسافات والاختلافات البسيطة.

في أول تشغيل، ينشئ السكربت مجلد `data` تلقائيا، ثم ينزّل — فقط إذا لم تكن موجودة — ملفات `channels.json` و`satellites.json` و`teams.json` و`competitions.json`. بعد ذلك ينشئ أو يحدّث `matches.json` و`channel_cache.json` و`last_run.json`. لا يستبدل أي ملف كتالوج موجود مسبقا.

## إعداد GitHub

أنشئ مستودعا، ارفع الملفات، ثم فعّل Actions. يفضّل إضافة الأسرار التالية من Settings → Secrets and variables → Actions:

- `FIREBASE_PROJECT_ID`: اختياري، والقيمة الافتراضية `satair-6983b`.
- `YS_PROXY_URL`: بروكسي يسمح بطلب POST إلى YSScores عند فشل Firebase. إذا تركته فارغا يستخدم القيمة الافتراضية الموجودة في الكود.
- `LST_PROXY_URL`: بروكسي LiveSoccerTV عند إضافة موصل القنوات التفصيلي لاحقا.
- `API_FOOTBALL_KEY`: اختياري، ويمكن استخدامه لاحقا لربط مصدر نتائج حي موثوق؛ لا يوضع داخل الملفات.

لأن GitHub يستخدم UTC ولا يضمن التحويل الموسمي لتوقيت مصر في تعبير cron، يتم التشغيل كل 10 دقائق، بينما يحسب السكربت اليوم والوقت داخليا بتوقيت `Africa/Cairo`. هذه الطريقة تضمن تحديث بداية اليوم وتحديث المباريات القريبة/الجارية دون الاعتماد على فرق التوقيت الصيفي.

## ملاحظات مهمة

المصادر العامة قد تغيّر HTML أو تضع حماية ضد الطلبات الآلية. لذلك جعلت البروكسي قابلا للتغيير عبر Secret، وحافظت على آخر نسخة ناجحة من JSON عند فشل المصدر. بيانات القنوات والترددات تأتي من الكتالوج المحلي ثم تُحفظ في `channel_cache.json`، فلا يعاد فتح صفحات القنوات لكل تشغيل. يجب احترام شروط استخدام كل مصدر وعدم رفع مفاتيح خاصة إلى GitHub.
